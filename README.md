Palm City Heat is a top-down 2D open-world crime game set in sun-soaked Palm City: explore four districts on foot and by car, steal and drive cars with drift physics, run a five-mission story for Rosa Delgado, Marco Vale and Benny Cole, work taxi fares and checkpoint street races, fight with fists and a pistol, and outrun a 0–5 star wanted system with chasing police, a full HUD and minimap, synthesized sound, and local saves — all fully offline in the browser.

## Run it

```sh
node serve.ts
```
then open http://localhost:8080 in a desktop browser.
